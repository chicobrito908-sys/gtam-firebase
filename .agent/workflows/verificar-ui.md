---
description: Como realizar a auditoria visual de interface usando um subagente no navegador
---
1. Iniciar o servidor de desenvolvimento: `npm run dev` (se não estiver rodando).
2. Abrir o `Agent Manager` e invocar o agente especialista em **UI/UX Auditor**.
3. O agente deve navegar até a página atual ou protótipo na pasta `/tmp/sandbox/`.
4. Realizar capturas de tela (screenshots) em resoluções mobile (360x800) e desktop (1440x900).
5. Gerar um relatório de auditoria destacando se os padrões "Navy & Purple" e "Mobile-First" foram respeitados.
